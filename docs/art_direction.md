# Art Direction

## Визуальный стиль

Чистый mobile utility без декоративного шума. Светлая база, мягкий sage, muted blue и amber для акцентов. Главный носитель качества — типографика, отступы, понятные состояния и реальные screenshots.

## Настроение

Спокойное, практичное, домашнее, без “мотивационного” давления.

## Палитра

- Background: `#FBFAF7`
- Text: `#232824`
- Muted text: `#617069`
- Primary sage: `#496B5A`
- Secondary blue: `#4D6575`
- Accent amber: `#E6B84E`

## Правила консистентности

- Не использовать случайные иллюстрации, маскотов, fake UI и мелкий текст внутри картинок.
- Store creatives делать только на основе реального UI или качественного ImageGen/design workflow.
- App icon должна быть простой и читаемой в launcher size: крупный знак checklist/timer/check, без текста, цифр, растений, маскотов, тяжёлых тёмных task dots и мелких декоративных деталей.
- Feature graphic: 1024x500, без мелкого текста и без имитации интерфейса.

## Хороший результат

Минималистичная композиция с крупным чистым символом порядка, мягкой палитрой и одной визуальной идеей.

## Плохой результат

Перегруженный баннер с мелким текстом, случайными карточками, псевдо-3D, ярким неоном или дешёвой AI-стилизацией.
