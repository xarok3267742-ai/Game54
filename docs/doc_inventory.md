## Automated Gate

`scripts/check_doc_inventory.py` verifies required documentation exists, is non-empty, contains expected key phrases, that this table stays synchronized with the checker source of truth and that no story bible file is present in release-owned source/documentation paths. The story-bible scan is bounded to avoid walking Gradle/build output. `scripts/check_doc_inventory_selftest.py` verifies the gate itself with temporary fixtures for missing files, directories, small files, missing markers, stale table rows, duplicate table rows and story bible exclusion.

`scripts/build_play_submission_packet.sh` copies this RC documentation set, plus the project `README.md` and `AGENTS.md`, into `play-submission`; `scripts/check_play_submission_doc_coverage.py` verifies every `REQUIRED_FILES` entry has a packet destination, allowlist entry and fresh packet copy. `scripts/check_play_submission_packet_contents.py` and `scripts/check_play_submission_packet_sync.py` keep that handoff packet allowlisted and byte-for-byte synchronized with the repository sources.
