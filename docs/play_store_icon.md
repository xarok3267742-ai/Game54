# Play Store Icon

## Asset

- Path: `store-assets/app-icon/play-store-icon-512.png`
- ImageGen source: `store-assets/app-icon/play-store-icon-imagegen-source-04.png`
- Size: 512x512 px
- Format: 32-bit PNG
- Status: `RC_READY`

## Source

The icon is generated by `scripts/generate_play_store_icon.py` from an ImageGen source. The current final Play PNG uses five large rounded checklist tiles, a clean completion check, a small home/order cue and a warm amber sparkle on a soft off-white brand background. It intentionally avoids the previous harsh task-dot composition and keeps the main shapes large for launcher-size readability. The same source also generates Android launcher PNG assets for mdpi, hdpi, xhdpi, xxhdpi and xxxhdpi densities.

No text, letters, numbers, people, badges, screenshots, decorative plants or policy-sensitive content are included. The ImageGen output was post-processed from a chroma-key source into an opaque store-ready icon before density generation.

## Automated Gate

`scripts/check_play_store_icon.py` verifies:

- PNG file exists;
- dimensions are exactly 512x512;
- PNG is 32-bit RGBA;
- file size is under 1024 KB.

`scripts/check_play_store_icon_selftest.py` verifies the gate itself with synthetic PNG headers for valid RGBA icons, non-PNG data, short headers, wrong dimensions, RGB color type, wrong bit depth and oversized files.

`scripts/check_packaged_app_contents.py` verifies that the built debug APK and release AAB include the raster launcher icon resources and no longer depend on the previous launcher foreground vector.

## Official Requirement

Google Play icon design specifications checked on 27 May 2026:

- 512x512 px;
- 32-bit PNG;
- maximum 1024 KB;
- Google Play dynamically applies rounded corners and drop shadow.

Source: https://developer.android.google.cn/distribute/google-play/resources/icon-design-specifications
